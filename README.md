# NovaSphere — прототип космического портала

Локальный одностраничный прототип портала о науке и технологиях с футуристичным космическим дизайном.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
cd space-portal
npx --yes serve .
```

Затем откройте адрес из терминала (обычно http://localhost:3000).

## Содержание

- Герой-блок с анимированными звёздами и счётчиками
- Свежие новости (Луна, Марс, технологии)
- Таймлайн покорения Луны
- Блок о Марсе с 3D-визуализацией планеты
- Карточки технологий будущего
- Таблица активных миссий

Данные демонстрационные, для учебного прототипа.
